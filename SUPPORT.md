# Support

- Use GitHub Issues for reproducible defects, documentation errors and feature proposals.
- Use GitHub Discussions, when enabled, for learning questions and design conversations.
- Use the private vulnerability reporting channel for security or privacy issues; see [`SECURITY.md`](SECURITY.md).

Before opening an issue, check the current release, `EXPERIMENT_STATUS.md`, `VALIDATION_REPORT.md` and existing issues. Include the operating system, architecture, Python version, exact command, minimal reproduction and sanitized logs.

This community project provides support on a best-effort basis and does not offer an SLA. Never post API keys, session cookies, proprietary data or unredacted agent traces.

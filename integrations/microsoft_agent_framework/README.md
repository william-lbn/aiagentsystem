# Microsoft Agent Framework integration track

Focus on workflow composition, checkpoint/resume, human-in-the-loop, observability and multi-agent orchestration. Because the framework is evolving quickly, follow the official setup page for the current package name/language and pin it in your own lab environment before collecting results.

Experiment: implement a two-step workflow, persist a checkpoint before an approval request, terminate the process, then resume and verify that the first successful step is not repeated.
